# v3.4 design — security pass on revision 2

Raw findings from the security agent (11 new, 5 accepted round-1 items under-specified). Verified against src/ by the agent.

- SEC2-1 (High, §2.2 P2): patch aimed at the wrong place. `CategoryPageService::deferFile` (line 51) builds the index path from the definition file's FILENAME, not `sanitizeCategoryName`. The empty slug actually reaches `CategoriesService::categorizeOutputPath` (line 154), which builds `dirname//file`; `TemplateRenderer.php:57` also uses it. Attack: category "!!!" writes the page uncategorized and can overwrite a same-named root page; a definition file named `..md` gets slug `.` and writes `public/./index.html`, overwriting the home page. Change: "The 3.3.7 guard lives in `categorizeOutputPath`, the category-template lookup, RobotsTxt, and `CategoryPageService::deferFile`. The filename-derived slug must match `^[a-z0-9]+(-[a-z0-9]+)*$`, else it is a build error. `OutputWriter` rejects any path whose realpath parent is outside `OUTPUT_DIR`."
- SEC2-2 (Medium, §3.2): "Without `--watch` the current code path is unchanged" keeps predictable `/tmp/staticforge-devserver-router-<pid>.php` (DevServerCommand.php:50) written with `file_put_contents` (follows symlinks). SEC-1/2 only fixed in watch mode. Change: private 0700 dir, temp+rename writes and `proc_open` argv apply to BOTH modes.
- SEC2-3 (Medium, §3.2 Router): containment only specified for `.html`; "everything else return false" hands non-HTML to `php -S`, incl. symlinks in `public/` pointing outside. Change: decode, NUL check and realpath containment run first for every request; outside root/unresolvable = 404; `return false` only after containment passes.
- SEC2-4 (Medium, §3.2 --host/state endpoint): guard wording ambiguous; with `--allow-remote`/0.0.0.0 under Lando, `error` sends build output (absolute paths, maybe config values) to the LAN; endpoint open to DNS rebinding. Change: refuse non-loopback host without `--allow-remote` unless `LANDO=ON` (then warn); `/__staticforge/*` returns 403 unless `Host` header is the bound host, localhost or the Lando host; `error` at most 5 lines with `app_root` replaced by `.`.
- SEC2-5 (High, §6.3): partial release "cleaned or ignored" lets rollback/prune pick an incomplete release and publish a broken site; leftover `current.tmp-*` links uncovered. Change: a release is complete only when `manifests/<id>.json` is written after upload with `errorCount === 0`; only complete releases are swap/rollback/keep candidates; partial-dir cleanup uses regex, lstat delete and the delete guard; `current.tmp-<id>` removed only after `lstat` shows a link; symlink target is the relative `releases/<id>`; `readlink` must equal that string exactly; `--rollback` argument must match the id regex.
- SEC2-6 (Medium, §6.1): `upload.*` validated only by advisory `audit:config`; `keep_releases: 0` behavior unstated. Change: `site:upload` validates `upload.*` at runtime and aborts on bad values (`max_delete` non-int or negative); `keep_releases` must be >= 1; current and the rollback target always kept.
- SEC2-7 (Medium, §6.3/7.4/12.1): outbound HTTP checks (canary, soft-404, autodiscovery) have no client requirements; canary mechanics undefined. Change: TLS verification on; 10 s timeout; redirects not followed (a 3xx on the random URL = soft-404 failure); requests only to the `SITE_BASE_URL` host; status checked before body. `site:upload` writes a random-name empty canary to `releases/<id>/` and checks it after the swap, warning loudly if reachable.
- SEC2-8 (Medium, §4.2/4.4): item set for `category_formats` Atom/JSON unspecified — may publish hidden pages (SEC-5 gap); §4.4 exclusions don't say they use `MetadataFlags`. Change: §4.4 hidden-page exclusions also apply to category Atom/JSON; categories in `exclude_categories` get no Atom/JSON; exclusion uses `MetadataFlags::isTrue/isFalse/robotsBlocked`.
- SEC2-9 (Low, §4.5/4.6): only Atom stated to use XMLWriter. Invalid UTF-8 makes `JSON_THROW_ON_ERROR`/XMLWriter fail the whole feed. Change: `Rss2Builder` uses XMLWriter; text passes through `mb_scrub` before control-char stripping and encoding; `feed_links` rendered with autoescape, never `|raw`.
- SEC2-10 (Low, §6.1): in `in_place` mode `staticforge-manifest.json` stays in the served tree, protected only by `.htaccess` (ignored by nginx/Cloudflare). Change: `audit:live` fetches the manifest URL and warns on 200; manual documents it.
- SEC2-11 (Low, §3.2): watcher excludes literal `public/`; if `OUTPUT_DIR` is elsewhere or inside `SOURCE_DIR`, every build retriggers itself and `--clean` runs repeatedly. Change: exclude the resolved `OUTPUT_DIR`; refuse `--watch` if `OUTPUT_DIR` is inside `SOURCE_DIR` or `TEMPLATE_DIR`.

Accepted round-1 items found under-specified: SEC-2 (watch only -> SEC2-2), SEC-5 (category formats/helper -> SEC2-8), SEC-6 (complete-release rule, rollback-arg regex, relative target -> SEC2-5), SEC-8 (canary creation/timing -> SEC2-7), SEC-10 (wrong sink -> SEC2-1). Adequately specified: SEC-1, 3, 4, 7, 9, 11, 12.
